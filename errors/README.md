# Errors and refusals

Every message a mod maker can meet, by code.

- [`errors.md`](errors.md): readable, one section per code: where you see it, the
  exact wording, what it means and the fix. Search it for a phrase from your
  message.
- [`errors.json`](errors.json): the same, for tools.

Each code is also a link: https://playaconline.com/modding/errors/#<code>. Codes never change, so a
link in a forum post keeps working.
